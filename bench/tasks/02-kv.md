Build a small key-value store CLI in this repository (Node.js, ES modules, no dependencies).

Entry point: bin/kv.js, run as `node bin/kv.js <command> [args] [--file <path>]`. The store is a JSON file; `--file` selects it and defaults to `.kv.json` in the current directory. Writes must be atomic (write a temporary file, then rename).

Commands:
- `set <key> <value...>`: stores the value (all remaining arguments joined with single spaces). Prints nothing, exit code 0. Optional `--ttl <seconds>` makes the key expire that many seconds after it was set.
- `get <key>`: prints the value followed by a newline, exit code 0. For a missing or expired key prints `not found: <key>` on stderr and exits with code 1. An expired key is removed from the file when it is read.
- `del <key>`: removes the key and prints `deleted`, exit 0; for a missing key prints `not found: <key>` on stderr and exits 1.
- `list`: prints every non-expired key, sorted, one per line; prints nothing for an empty store.

Keys must match /^[A-Za-z0-9_.-]+$/; otherwise print `invalid key: <key>` on stderr and exit 1. An unknown command prints usage on stderr and exits 2.

Add tests in test/ using node:test that run the CLI as a child process against a temporary file and cover every command, the error cases and TTL expiry (use a short TTL and a fake clock or an already-expired timestamp; the file stores absolute expiry times in milliseconds).
