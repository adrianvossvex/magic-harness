**Contract behaviour**

Success prints exactly one `JSON.stringify` value on stdout and exits 0, saving the store first for mutating commands. Module errors and unparsable values print `{"error":"<message>"}` on stderr and exit 2. Unknown command, unknown option, or a missing required option prints the usage text on stderr with nothing on stdout and exits 1.
