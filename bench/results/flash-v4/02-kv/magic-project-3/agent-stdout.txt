**What I built**

`src/store.js` is a pure ES module with the exported contract from the design: `KEY_PATTERN`, `isValidKey`, `makeEntry`, `isExpired`, `pruneExpired`, `readStore`, `writeStore`, and `StoreError`. It imports only `node:fs` and `node:crypto` and knows nothing about argv or commands.

- `readStore` returns an `Object.create(null)` map; a missing file (ENOENT) yields an empty map, while any other read failure, corrupt JSON, a non-object/array root, or a malformed entry throws `StoreError` whose message names the file.
- `writeStore` serialises `JSON.stringify(entries, null, 2) + '\n'`, writes to `"${filePath}.${process.pid}.${randomBytes(6).toString('hex')}.tmp"` with flag `'wx'`, renames over the target, and on any failure unlinks the temp file best-effort and throws `StoreError`.
- `pruneExpired` builds a new null-prototype map and never mutates its input; expiry is `expiresAt != null && now >= expiresAt`.

`test/store.test.js` reads and writes only inside directories from `fs.mkdtempSync(os.tmpdir())`, cleaned up via `t.after`.
