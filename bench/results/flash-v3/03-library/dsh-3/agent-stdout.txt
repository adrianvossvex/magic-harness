## Key design decisions
- **Storage** is a single JSON doc `{ books, members, loans, sequences }`; `setDataFile()` (driven by `--data`) configures it. `read()` creates the file on first use, and `write()` is atomic (temp file + rename). Ids come from persisted per-entity sequence counters, starting at 1.
- **Dates** are `YYYY-MM-DD` strings handled through UTC timestamps, so day arithmetic is DST-proof. `today` defaults to the local current date and is validated when supplied.
- **Rules**: `available` starts at `copies`, decrements on checkout, restores on return (capped at `copies`); checkout fails at 0 copies or 3 active loans; a 0.50/day late fine capped at 20.00; double return fails.
- **CLI errors**: required/unknown options and unknown commands are `UsageError` → exit 1; validation/business failures → exit 2. Output is one JSON value per command.
