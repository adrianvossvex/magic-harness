**What's there**

- `src/books.js` — `addBook({ title, author, copies = 1 })`, `listBooks({ available })`; a book is `{ id, title, author, copies, available }`, where `available` is the count of copies still on the shelf (it drops on checkout and comes back on return).
- `src/members.js` — `addMember({ name })`; a member is `{ id, name }`.
- `src/loans.js` — `checkout`, `returnLoan`, `listLoans`, `report`, with the loan shape, the 3-active-loan limit, and the 0.50/day fine capped at 20.00. Fines are computed in cents and the report sums them in cents, so no floating-point drift.
- `src/store.js`, `src/dates.js`, `src/validate.js` — persistence (one JSON file `data/library.json`, created on first use along with its directory, keys `books`/`members`/`loans`/`nextId`), UTC-based date arithmetic so DST can't shift a day boundary, and option validation.
- `bin/library.js` — the CLI. Success prints pretty-printed JSON on stdout and exits 0; failures print `{"error": "..."}` on stderr and exit 2; usage mistakes (unknown command, unknown option, missing option or value, stray argument) exit 1.
- `test/` — `books.test.js`, `members.test.js`, `loans.test.js`, `cli.test.js` (spawns the real binary and checks stdout/stderr/exit codes), plus `test/helpers.js` for throwaway temp data files. Tests never touch the working directory.
- `README.md` — modules, every command with a runnable example, and the rules.

**Decisions worth knowing**

- Each module function takes an optional `data` key in its options object (default `data/library.json`), since the signatures you gave carry no path. The CLI passes `--data` straight through.
- `fine` starts at `0` on an active loan and is set on return; `report.finesOwed` sums fines of returned loans only.
- `list-loans` without `--overdue` returns a member's loans whether or not they were returned; with `--overdue` it keeps only active loans whose due date is strictly before today.
- I treat unknown options and stray arguments as exit 1 alongside the cases you specified, since they're the same class of usage error.
