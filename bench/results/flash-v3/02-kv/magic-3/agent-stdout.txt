**Behavior notes worth knowing**

- `set` joins all remaining arguments with single spaces; `--file`/`--ttl` are extracted wherever they appear, so `set k --flag` stores the literal string `--flag`. For the other commands an unrecognized `--option` is a usage error.
- `--ttl` accepts fractional seconds (and `0`, which expires immediately), and the file stores `expiresAt` as absolute epoch milliseconds. Setting a key without `--ttl` clears a previous expiry.
- Expired keys are pruned from the file whenever a command loads the store and finds expired entries, which is what removes a key when it is read. `get`/`del` report expired keys as `not found: <key>` with exit 1.
- Exit codes: 1 for missing/expired key, invalid key, invalid `--ttl`, or a malformed store file; 2 for unknown command, unknown option, or missing/extra arguments (these print usage on stderr).
- `node --test test/` failed on this Node version (it tried to load `test` as a module), which is why the npm script uses a glob pattern; plain `node --test` also works.
