**Decisions the spec left open** (all documented in the README):

- Missing operands (`get` with no key, `set` with no value) are treated as usage errors: usage on stderr, exit 2. `set k ""` still stores an empty string, since that's one explicit argument.
- `list` filters out expired keys but doesn't rewrite the file; only `get` and `del` purge, matching "an expired key is removed when it is read."
- A store file that isn't a JSON object produces `error: ...` on stderr and exit 1.
- TTL accepts fractional seconds, which let the tests use a 200 ms TTL instead of sleeping for a full second.

One small snag worth noting: on this Node (v26), `node --test test/` tried to load `test/` as a module and failed, so the script uses plain `node --test`, which auto-discovers `test/cli.test.js`.
