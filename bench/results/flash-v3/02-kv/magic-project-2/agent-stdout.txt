## One thing worth knowing

The design assumed `node --test test/` directory-scans the folder, but on the installed **Node v26** a bare directory argument to `--test` is resolved as a module entry point, so `node --test test/` failed with `MODULE_NOT_FOUND`. I added `test/index.js`, which imports the four suites; the required invocations now resolve the directory to it and run everything. The trade-off: `node --test` with *no* arguments (auto-discovery) loads both `index.js` and the suites directly, so tests run twice there (49 pass) — the documented and acceptance invocations run them once. I recorded this in the decision log.
