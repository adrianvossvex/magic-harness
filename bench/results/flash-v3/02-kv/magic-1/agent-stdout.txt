**Store format and behavior**

The file is a JSON object mapping key to `{ value, expiresAt }`, where `expiresAt` is `null` for a key that never expires or an absolute Unix-epoch timestamp in milliseconds. Writes go to a temp file in the same directory followed by a rename. A missing or empty file is treated as an empty store. Commands:

- `set` writes atomically and prints nothing (exit 0).
- `get` prints the value plus newline (exit 0); a missing key prints `not found: <key>` on stderr (exit 1); reading an expired key deletes it from the file before reporting it missing.
- `del` prints `deleted` (exit 0), or `not found: <key>` on stderr (exit 1); an expired key counts as missing and is pruned.
- `list` prints non-expired keys sorted, one per line, nothing when empty (exit 0).
- Invalid keys print `invalid key: <key>` on stderr (exit 1); an unknown command or missing command prints usage on stderr (exit 2).
