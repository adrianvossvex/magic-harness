## What was created

- **`bin/kv.js`** — CLI entry point. Parses `<command> [args] [--file <path>]`, plus `--ttl <seconds>` for `set`, and dispatches `set`/`get`/`del`/`list`.
- **`src/store.js`** — store logic: JSON load/save, atomic writes (unique temp file in the same directory, then `rename`), key validation, and expiry helpers.
- **`test/cli.test.js`** — 22 `node:test` cases running the CLI as a child process against temp files.
- **`README.md`** — documents every command, keys, exit codes, and the store format.
- **`package.json`** — added `"scripts": { "test": "node --test" }` and a `bin` entry.
- **`.gitignore`** — ignores `.kv.json` and `*.tmp`.

## Behavior implemented

| Command | Behavior |
|---|---|
| `set <key> <value...> [--ttl <s>]` | joins remaining args with single spaces; stores `expiresAt` (absolute ms) or `null`; silent, exit 0 |
| `get <key>` | value + newline, exit 0; missing/expired → `not found: <key>` on stderr, exit 1, expired entry removed from file |
| `del <key>` | `deleted`, exit 0; missing/expired → `not found: <key>` on stderr, exit 1 |
| `list` | sorted non-expired keys, one per line; silent when empty |

Invalid keys (`/^[A-Za-z0-9_.-]+$/`) print `invalid key: <key>` on stderr and exit 1; unknown commands print usage on stderr and exit 2. Store defaults to `.kv.json` in the cwd.
