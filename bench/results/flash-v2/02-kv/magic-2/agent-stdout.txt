## What I built

**`bin/kv.js`** — the CLI. It strips `--file` and `--ttl` from the argument list wherever they appear, so flags can go before or after positional arguments. It dispatches to `set`/`get`/`del`/`list` and returns an exit code rather than calling `process.exit`, which avoids truncating output.

**`src/store.js`** — the storage layer: key validation, read/normalize, the atomic write, and expiry helpers. Writes go to a temporary file in the same directory (so the rename stays on one filesystem) and are then renamed over the target; the temp file is removed if anything fails.

**`test/kv.test.js`** — 37 tests using `node:test`, each running the CLI as a child process against a fresh temp directory. **`README.md`** documents every command, both options, key rules, exit codes, and the file format. `package.json` gained `"test": "node --test"` and a `bin` entry.

## Decisions worth flagging

- **Expiry semantics.** `expiresAt` is an absolute millisecond timestamp, omitted for keys with no TTL. A key is expired when `now >= expiresAt`, so `--ttl 0` expires immediately — that plus writing a past timestamp directly into the file is how the tests cover expiry deterministically, with no sleeping and no flakiness.
- **Pruning.** The spec requires `get` to remove an expired key; I also prune during `list` (it's a read too) and have `del` treat an expired key as missing while removing it. All three are documented.
- **A corrupt store is an error, not an empty store.** If the JSON can't be parsed or has no `entries` object, the command fails with exit 1 instead of continuing. Treating it as empty would mean the next `set` silently wipes the user's data, and there's a test asserting the file is left untouched.
- **A top-level `{version, entries}` wrapper** rather than a bare key→value map, so a legitimate key named `version` or `entries` can't collide with metadata.
- **Usage errors are strict**: unknown options, invalid `--ttl` values, `--ttl` on a non-`set` command, and wrong argument counts all print usage to stderr and exit 2. Note `--file=path` is not supported, only `--file path`.

Two bugs the tests caught during development, both now fixed: `--ttl ''` was being accepted because `Number('')` is `0`, and `del` on an expired key was reporting success instead of `not found`.
