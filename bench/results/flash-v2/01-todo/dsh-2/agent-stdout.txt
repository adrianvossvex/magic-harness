One thing worth flagging: `add` keeps the original `id: items.length + 1` scheme. Since removing an item reduces the count, adding afterward can reuse an id (e.g. add a, add b, remove a, add c → c gets id 2, colliding with b). I left `add` exactly as-is per the instruction to keep it working as it was, but if you'd like I can switch to a monotonic id counter to avoid that collision.
