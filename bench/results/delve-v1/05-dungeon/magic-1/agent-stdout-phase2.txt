**Core** (`src/game.js`): every turn-costing action now pushes a snapshot onto `game.state.history` — a deep copy of the state plus the generator state and the id counter — and `game.undo()` pops it, restores all three, and returns `true` (or `false` when the stack is empty). Because the snapshot is a full copy rather than a reverse replay, a rewind is exact: hit points, monsters, items, log, level and depth all come back, a descent is undone back to the previous level, and the turn that killed you can be taken back too. The stack is capped at ten; the eleventh push drops the oldest. `game.state.undo` mirrors the stack size and both fields live in the state, so `serialize()`/`loadGame()` carry the ability to rewind. `hash()` skips `history` and `undo`, so the hash before a turn equals the hash after that turn is undone.

**Keys**: `applyKey(game, 'z')` calls `undo()` and returns `["You rewind time."]` or `["Nothing to rewind."]`. Those messages are deliberately never written to `state.log`, since the log has to come back exactly as it was — the rewind announces itself through the return value, the HUD and the renderer instead. `runScript` picks `z` up for free.
