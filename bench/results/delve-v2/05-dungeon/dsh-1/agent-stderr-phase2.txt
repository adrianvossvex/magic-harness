## Requirements

1. `game.undo()` reverts the most recent turn-costing action:
   - state exactly as it was before that action: rng state, log, monsters, level, depth
   - undo right after descending brings previous level back
   - Actions costing no turn leave nothing to undo
   - returns `true` when a turn undone, `false` otherwise
   - Up to 10 turns can be undone in a row; older history discarded.

2. `game.state.undo` holds number of turns that can currently be undone (0..10), part of state; history stored as `game.state.history`, so `serialize()` and `loadGame()` preserve it.
   - `hash()` ignores `history` and `undo` fields.

3. `game.hash()` before an action equals `game.hash()` after that action has been undone.
   - Acting again after an undo behaves exactly as the first time (same rng, same result).

4. `applyKey(game, "z")` calls `undo()` and returns an array of messages: `["You rewind time."]` when a turn was undone, `["Nothing to rewind."]` otherwise.
   - `runScript` accepts `z` like any other key.

5. Page: `z` key rewinds, HUD (`id="hud"`) shows `Undo N` with current count, renderer shows rewound state at once (positions, hp, log, level) with a brief visual cue.

6. Add tests for rewind to project test suite and document feature in README. `npm test` must pass.
