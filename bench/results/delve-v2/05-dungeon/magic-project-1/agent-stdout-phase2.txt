What changed:

- **State**: `undo` (0..10, always `history.length`) and `history` (up to ten pre-action snapshots, newest last) were added as ordinary state fields, so `serialize()`/`loadGame()` carry them with no special case.
- **`act()`**: each of the six known action types takes a snapshot (deep JSON copy with `history`/`undo` removed and `rng` set to the live generator state) *before* the action resolves, and pushes it only when the action cost a turn, before `turn += 1` and before the monster turn. Free actions change nothing.
- **`game.undo()`**: restores the newest snapshot in place — `rng.state` first, then copies every entry key onto the same state object (identity preserved) and shortens `history`/`undo`. It ignores `status`, never touches `turn`, never consumes the rng and never writes the log.
- **`hash()`**: drops exactly the top-level `history` and `undo`, so hash-before-action equals hash-after-undo and act-undo-act reproduces the same result.
- **`applyKey(game, 'z')`**: calls `undo()` and returns `['You rewind time.']` / `['Nothing to rewind.']` as a return value only; `runScript` accepts `z` like any other character.
